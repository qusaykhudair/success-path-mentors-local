# Germany Expansion Architecture

## Approved Decisions

- North America currently uses /en and /ar.
- Existing URLs must not be migrated.
- Germany is a market, not merely another global language.
- Planned Germany namespace:

  ```text
  /de
  /de/de
  /de/en
  /de/ar
  ```

- First segment /de means Germany market.
- Second segment means Germany market language.
- Germany default language is de.
- Germany supported languages are de/ar/en.
- Germany remains disabled until explicitly activated.
- Do not add de to the global next-intl locales simply to implement Germany.
- French /fr architecture must not be copied as the Germany architecture.
- Current Canada/US location SEO architecture remains North-America-specific until a separate Germany location strategy is approved.
