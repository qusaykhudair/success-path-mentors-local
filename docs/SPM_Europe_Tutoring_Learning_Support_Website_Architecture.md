# SPM Europe Tutoring & Learning Support Website Architecture
Primary source of truth for the tutoring services architecture, page structure, naming, website copy, service positioning, and implementation requirements.

## CRITICAL BUSINESS POSITIONING
Success Path Mentors Europe is a **tutoring and educational support service**.
It is NOT:
* an accredited educational institution,
* a certification provider,
* an examination body,
* an awarding organization.

We provide:
* private tutoring,
* one-to-one lessons,
* small-group tutoring,
* language reinforcement,
* academic support,
* school-subject tutoring,
* homework support,
* exam preparation support,
* learning-gap recovery,
* support to improve language proficiency,
* support to improve academic achievement.

We DO NOT issue:
* accredited qualifications,
* official language certificates,
* CEFR certificates,
* Goethe certificates,
* telc certificates,
* DELF/DALF certificates,
* diplomas or accredited awards.

If CEFR levels such as A1, A2, B1, B2, C1 and C2 are shown, they must be presented only as a reference for identifying the learner's approximate level and organizing appropriate tutoring support.
Never write copy that implies accreditation or official certification.

Disclaimer:
"Success Path Mentors uses CEFR levels as a reference to help identify a learner's current language ability and organize appropriate tutoring support. We do not issue official CEFR certificates or accredited language qualifications."
