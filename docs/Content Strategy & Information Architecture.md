# 10 - Content Strategy & Information Architecture

> Project: Success Path Mentors

> Version: 1.0

> Priority: Critical

---

# Purpose

This document defines the complete Information Architecture (IA), Content Strategy, Navigation Structure, and SEO hierarchy for the Success Path Mentors website.

The objective is to create a scalable, search-engine-friendly website with a logical structure that improves user experience, discoverability, and topical authority.

---

# Information Architecture Principles

The website architecture must follow these principles:

- Shallow navigation (maximum 3 clicks to any page)
- Clear hierarchy
- SEO-first structure
- Logical grouping
- No orphan pages
- Strong internal linking
- Scalable architecture
- User-centered navigation

# Page Relationships

Every Subject Page should link to:

- Related Services
- Related Locations
- Blog Articles
- FAQ
- Contact

Every Service Page should link to:

- Subjects
- Locations
- Testimonials
- Contact

Every Location Page should link to:

- Subjects
- Services
- Local Testimonials
- Local FAQ

Every Blog Article should link to:

- Related Subjects
- Related Services
- FAQ
- Contact

---

# Topical Authority Strategy

Build topic clusters around three core pillars:

## Subjects

Each subject should include:

- Overview
- Benefits
- Curriculum
- Common Challenges
- Tutor Expertise
- FAQ
- CTA

---

## Services

Each service should include:

- Overview
- Benefits
- Process
- Why Choose Us
- Testimonials
- FAQ
- CTA

---

## Locations

Each location should include:

- Local Introduction
- Available Subjects
- Available Services
- Testimonials
- FAQ
- Contact

---

# Internal Linking Strategy

Every page must contain contextual links to:

- Parent category
- Related pages
- FAQ
- Contact
- Blog
- Homepage

Avoid isolated pages.

---

# Landing Page Template

Every landing page should follow this structure:

1. Hero
2. Introduction
3. Benefits
4. Features
5. Statistics
6. Testimonials
7. FAQ
8. CTA

---

# Content Hierarchy

Each page should follow:

H1

↓

Introduction

↓

H2 Sections

↓

Supporting H3

↓

CTA

Never skip heading levels.

Each page should include:

- Related Questions

- Schema.org
