# Development Rules

- Generate all service pages from structured data.
- Reuse the same page template for every service.
- Keep layout consistent across services.
- Localize all content.
- Support Arabic and English.
- Generate dynamic metadata.
- Generate JSON-LD automatically.
- Optimize images and performance.
- Use reusable components only.

---

# Expected Outcome

Every tutoring service page should function as a premium, SEO-optimized landing page that clearly explains the service, builds credibility, answers common questions, and encourages visitors to book tutoring sessions while maintaining consistency, scalability, and excellent user experience across all services.
