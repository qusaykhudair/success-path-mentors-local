# 14 - Services Overview Page Specification

> Project: Success Path Mentors

> Framework: Next.js 15

> Page Type: SEO Landing Page

> Priority: Critical

> SEO Level: Maximum

---

# Purpose

The Services page is the primary hub that showcases all tutoring services offered by Success Path Mentors.

It should help visitors quickly understand available learning options while supporting Programmatic SEO and increasing conversions.

- Increase tutoring inquiries
- Improve service discoverability
- Increase conversions
- Improve organic search rankings
- Build trust
- Educate visitors

# Future Scalability

The page must support unlimited services without changing the layout.

All cards should be generated dynamically from structured data.

No hardcoded content.

---

# Development Rules

- Generate service cards dynamically.
- Use reusable components.
- Localize all content.
- Support RTL and LTR.
- Generate dynamic metadata.
- Include structured data.
- Optimize SEO and performance.

---

# Expected Outcome

The Services page should become the primary gateway for visitors exploring tutoring options, providing a clear overview of all available services while maximizing SEO performance, usability, and conversion opportunities.
