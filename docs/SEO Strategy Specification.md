# SEO Philosophy

Search Engine Optimization is the highest priority of this project.

Every design decision, component, page, image, heading, and content block should be built with SEO in mind before visual appearance.

The website should be optimized for:

- Google
- Bing
- Yahoo
- DuckDuckGo
- AI Search Engines
- ChatGPT Browsing
- Gemini
- Perplexity

---

# SEO Goals

The website should:

- Rank for tutoring services
- Rank for tutoring locations
- Rank for tutoring subjects
- Rank for educational resources
- Generate organic traffic
- Increase local visibility
- Improve conversion rate
- Improve click-through rate
