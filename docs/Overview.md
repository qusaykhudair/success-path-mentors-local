# Project Vision

The objective of this project is **not** to clone the existing Success Path Mentors website.

Instead, the current website should be considered a **content, branding, and business reference only**.

The new website must be completely redesigned using modern UI/UX principles while preserving the existing brand identity, educational messaging, and visual language.

The final product should feel like a premium international education platform comparable to:

- Preply
- Varsity Tutors
- Superprof
- Wyzant
- Tutor Doctor

while maintaining the Success Path Mentors identity.

# Core Principles

Every development decision must respect the following principles:

## 1. Preserve Brand Identity

The website must preserve:

- Logo
- Brand colors
- Overall visual identity
- Educational messaging
- Trust-focused branding

The interface itself may be redesigned completely.

---

## 2. Modern UI

Avoid copying the existing layout.

Instead:

Redesign every page according to modern UX standards.

---

## 3. Clean Architecture

The project must follow enterprise architecture.

Avoid:

- duplicated components
- duplicated pages
- duplicated logic

Everything should be reusable.

---

## 4. Performance First

Every page should be optimized for:

- Lighthouse
- Core Web Vitals
- Accessibility
- SEO
- Performance

---

## 5. SEO First

SEO is the highest priority of this project.

Every page must be designed for search engines before visual appearance.
