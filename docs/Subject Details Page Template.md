# Purpose

This template defines the structure for every tutoring subject page.

Examples:

- Math Tutoring
- English Tutoring
- French Tutoring
- Science Tutoring
- Chemistry Tutoring
- Biology Tutoring
- Physics Tutoring
- History Tutoring
- Geography Tutoring

Every subject page must be generated dynamically while maintaining identical layout, SEO quality, accessibility, and user experience.

# Development Rules

- Generate all pages from structured data.
- Avoid duplicated layouts.
- Use reusable components.
- Localize all content.
- Support RTL and LTR.
- Generate dynamic metadata.
- Include structured data for every page.
- Optimize images and performance.

---

# Expected Outcome

Every tutoring subject page should function as a high-quality, SEO-optimized landing page that educates visitors, builds trust, showcases expertise, and encourages users to book tutoring services. The template should support unlimited subjects through dynamic data while maintaining consistent design, accessibility, and performance standards.
