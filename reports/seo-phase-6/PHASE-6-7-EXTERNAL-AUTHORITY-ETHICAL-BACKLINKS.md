## 1. Objective

Phase 6.7 establishes a controlled external-authority program for Success Path Mentors.

The goal is not to accumulate as many backlinks as possible. The goal is to earn or qualify **relevant third-party citations, listings, partnerships, resource references, and editorial mentions** that are credible for a Grades 1–12 online tutoring business serving families in Canada and the United States.

The operating principle is:

> **Relevance + real-world value + editorial or directory legitimacy first. Link value is secondary.**

This phase does **not** send outreach, purchase memberships, buy sponsorships, or claim that a backlink has been acquired. It establishes the verified launch queue, evidence standard, controls, and measurement fields required before those actions happen.

## 3. Allowed / conditional / blocked tactics

### 3.1 ALLOW

These tactics are acceptable when the target is relevant and the business information is factual:

- education-resource directories that explicitly accept tutoring providers;
- legitimate local business directories tied to real membership or local business participation;
- youth/community networks where Success Path Mentors can participate substantively;
- educational-resource contributions that are useful without requiring a commercial landing-page pitch;
- earned media based on a real newsworthy event, initiative, partnership, study, program, or community contribution;
- co-created educational resources with community organizations;
- partnership pages or mentions that arise from a real operating relationship.

### 3.2 CONDITIONAL

These require an additional business-value or editorial-value gate:

- paid Chamber membership;
- sponsorships;
- event participation;
- local advertising;
- community partnerships that require financial or operational commitment;
- digital PR pitches;
- directory listings that require membership or paid inclusion.

A conditional opportunity may be approved only when the **non-SEO business/community value is independently defensible**.

### 3.3 BLOCK

The following are not part of the Success Path Mentors SEO program:

- paid backlink marketplaces;
- private blog networks;
- rented backlinks;
- bulk low-quality directory submissions;
- automated backlink blasts;
- forced reciprocal-link schemes;
- exact-match anchor-text manipulation;
- guest-post farms;
- fake review or testimonial placements;
- fabricated partnerships, memberships, awards, sponsorships, media mentions, credentials, or rankings;
- outreach that uses unverified tutor degrees, certifications, background-check claims, review counts, pass rates, student counts, grade gains, or guaranteed outcomes.

## 4. Prospect qualification model

Each external-authority prospect must be evaluated across the following gates.

### Gate A — Relevance

The target must be relevant to at least one of:

- K–12 education;
- tutoring;
- Ontario / Canadian families;
- Milton / Halton community;
- youth services;
- newcomer-family support;
- parent education;
- curriculum or learning resources.

### Gate B — Legitimacy

The organization or publication must have a clear public identity, real operating purpose, and a verifiable current website.

### Gate C — Natural placement

The mention, directory listing, partnership, or resource reference must make sense to a real user even if search engines did not exist.

### Gate D — Claim safety

Any copy supplied by Success Path Mentors must use only claims already supported by the Phase 6.6 trust layer.

### Gate E — Business approval

Any action that creates a fee, membership, sponsorship, public partnership, formal commitment, or external message requires business approval before submission.

### Gate F — Measurement

Every launched opportunity should record:

- prospect;
- target URL;
- outreach date;
- contact channel;
- owner;
- status;
- cost, if any;
- destination SPM URL;
- mention URL, if earned;
- link present: yes/no;
- follow / nofollow / unknown;
- referral sessions;
- assisted trial starts, if measurable;
- notes.

## 7. Outreach copy controls

Any future outreach should follow these rules:

### Safe factual base

Approved factual themes include:

- personalized one-to-one online tutoring;
- Grades 1–12;
- Math, English, Science, French and other supported tutoring areas when accurate for the destination;
- curriculum-aware support;
- tutor matching based on student needs and operational fit;
- family communication and scheduling support;
- official website and contact information.

### Claims that remain blocked without additional evidence

Do not state or imply:

- all tutors hold a specific credential;
- tutors are background checked unless a verified program exists;
- a specific number of students, teachers, or years of experience unless intentionally sourced and approved;
- star ratings or review counts without auditable provenance;
- guaranteed grades, pass rates, admissions, exam results, or grade improvements;
- awards, memberships, partnerships, sponsorships, or media recognition before they are real.

## 8. Anchor and destination policy

The program does not optimize external anchors aggressively.

Preferred natural references:

- `Success Path Mentors`
- `Success Path Mentors online tutoring`
- plain website URL
- context-driven descriptive references chosen by the third party

Do not request exact-match anchors such as repeated city+subject keyword combinations.

Destination priority:

- homepage for general company/business listings;
- relevant subject/service owner only when the referring page is specifically about that topic;
- local owner only when the placement is genuinely location-specific;
- no creation of a new landing page merely to receive a backlink.

The established ownership hierarchy remains:

`Course code / named course → Service → Subject → Curriculum → Generic Location`

## 9. Measurement framework

Acquired authority should be measured by quality and downstream value, not raw backlink count.

Primary fields:

| Field | Purpose |
|---|---|
| Prospect | Entity contacted or joined |
| Opportunity type | Directory / partnership / media / resource |
| Status | Qualified / approved / submitted / live / declined / hold |
| Cost | Membership or sponsorship cost when applicable |
| Placement URL | Third-party live page |
| Destination URL | SPM owner receiving the link/mention |
| Link present | Yes / No |
| Link attribute | Follow / nofollow / unknown |
| Relevance | High / Medium / Low |
| Referral sessions | Traffic quality indicator |
| Trial starts | Funnel contribution |
| Registrations | Downstream contribution |
| Notes | Relationship / editorial context |

No authority program success claim should be made from a raw increase in backlink count alone.
