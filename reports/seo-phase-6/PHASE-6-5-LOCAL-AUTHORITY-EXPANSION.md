## 1. Purpose

Phase 6.5 translates the local-demand families discovered in Phase 6.2 and filtered through the Phase 6.4 new-page gate into a controlled local-authority operating model.

The objective is not to create more city URLs.

The objective is to determine which **existing generic location owners** deserve continued watch, which should remain on hold, which need an owner-fit review, and what evidence must exist before a material local optimization is allowed.

The operating rule is:

> **Strengthen the correct existing location owner before considering local URL expansion.**

This phase is documentation and control only. It introduces no production runtime, routing, title, meta, H1, canonical, CTA or page-content change.

## 3. Governing owner rule

Generic geographic tutoring intent belongs to the generic location owner when one already exists.

Examples:

- `online tutoring alexandria va` → Alexandria location owner;
- `online tutoring hamilton on` → Hamilton location owner;
- `online tutoring naperville` → Naperville location owner;
- `online tutoring west cedar rapids` → Cedar Rapids location owner;
- `tutoring new orleans` → New Orleans location owner.

A geography modifier does not override a stronger educational owner.

Examples:

- `Hamilton chemistry tutoring` → Chemistry subject owner, not a Hamilton+Chemistry page;
- `Naperville math tutoring` → Math subject owner, not a Naperville+Math page;
- `Alexandria homework help` → Homework Help service owner, not an Alexandria+Homework page;
- `MHF4U tutor Hamilton` → MHF4U course owner, not a Hamilton+MHF4U page.

The owner precedence remains:

**Course / named course → Service → Subject → Curriculum → Generic Location → Homepage for brand**

## 4. Existing-owner promotion gate

Phase 6.5 carries forward the established local-owner promotion rule from Phase 4.1.

An existing generic location owner becomes eligible for a material optimization review when any of the following occurs over a rolling 56-day period:

1. **25+ impressions** for the coherent local cluster across at least **4 distinct weeks**; or
2. **3+ organic clicks**; or
3. a clear **multi-week acceleration** in impressions together with a documented current-page content, snippet, trust or internal-link gap.

These are internal operating thresholds, not universal SEO rules.

Crossing the threshold means **eligible for review**. It does not mean an automatic rewrite.

The review sequence after eligibility is:

1. confirm owner correctness;
2. confirm the signal is generic local tutoring rather than a stronger subject/service/course intent;
3. inspect current title/meta/H1 and content for a real gap;
4. inspect local trust/supporting context;
5. inspect internal links and anchor intent;
6. check cannibalization risk;
7. choose the smallest evidence-backed patch;
8. register the intervention as a measured experiment where material.

A new URL remains governed separately by the stricter Phase 6.4 CREATE gate.

## 15. Doorway-pattern rejection

Phase 6.5 explicitly rejects local growth through city-topic multiplication.

Rejected patterns include:

- city + subject;
- city + course;
- city + service;
- neighborhood + subject;
- neighborhood + service;
- duplicate city pages for wording variants.

Examples:

- `/hamilton/math`;
- `/alexandria/english`;
- `/naperville/french`;
- `/cedar-rapids/science`;
- `/hamilton/mhf4u`;
- `/alexandria/homework-help`.

When a query expresses a stronger subject/course/service intent, the stronger existing owner receives that intent.

The location page may provide contextual local availability and link to the stronger owner without becoming a duplicate specialist page.

## 16. Local authority actions that are allowed after eligibility

Once an existing location owner passes the promotion gate, Phase 6.5 permits an evidence-backed QA review of the following areas before deciding whether to patch:

### A. Intent clarity

Confirm that the page clearly owns generic local online tutoring intent rather than trying to own every subject/service query.

### B. Snippet alignment

Review title and description only if impression volume is sufficient and the snippet has a documented mismatch with the stable query family.

### C. Local relevance

Check whether the page accurately describes availability, delivery model and geographic context without implying a physical centre when none exists.

### D. Trust support

Check whether appropriate business-level trust elements can be referenced consistently, such as tutoring model, teacher selection, assessment approach, progress reporting and parent communication.

Detailed trust implementation belongs to Phase 6.6.

### E. Internal links

Check whether the location owner can naturally link users to the appropriate Math, English, Science, French, Chemistry, Physics, Homework Help, Exam Preparation or curriculum owners.

Do not use those links to transform the location page into a competing subject owner.

### F. Conversion path

Confirm the existing free-trial / booking path is usable and attribution-safe.

### G. Schema/factual consistency

Review structured data and visible facts for parity if a future patch materially changes the page.

## 17. Local authority actions blocked before eligibility

Before an existing owner crosses the evidence gate, Phase 6.5 blocks:

- broad copy rewrites;
- title/H1/meta retargeting;
- local FAQ proliferation;
- mass local-link blocks;
- schema expansion based on keyword variants;
- new neighborhood pages;
- new city pages from isolated impressions;
- city-topic doorway routes.

The objective is to avoid confusing Google about ownership while the measurement window is still immature.
